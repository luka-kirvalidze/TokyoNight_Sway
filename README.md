# TokyoNight_Sway
minimal dotfiles for sway with tokyonight theme!

# Requirements
1) alacritty
2) fastfetch
3) neovim
4) rofi
5) sway, swaylock, swaybg, swaync
6) waybar

# Installation:
1) git clone https://github.com/luka-kirvalidze/TokyoNight_Sway.git
2) cd TokyoNight_Sway
3) stow -v -t $HOME {filename}
